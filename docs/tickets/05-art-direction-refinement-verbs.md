# 05: Art Direction Refinement Verbs

**What to build:** The capability for an agent to perform creative refinements on existing SVG assets using expressive direction commands (`bolder`, `quieter`, `distill`, `delight`, `animate`, `critique`), modifying stroke weights, luminescence, clutter density, or adding motion without requiring the user to specify coordinate-level edits.

**Blocked by:** 03: OBS Streaming Overlays Pipeline (Experience Mode), 04: Dashboard Widgets and Power BI DAX Pipeline (Operate Mode).

**Status:** ready-for-agent

- [ ] `/svg-maestro bolder` successfully amplifies stroke weights, gradient contrasts, and luminescent glows on a target SVG
- [ ] `/svg-maestro quieter` reduces saturation and softens lighting for an understated look
- [ ] `/svg-maestro distill` strips secondary decorative shapes while preserving core geometric hierarchy
- [ ] `/svg-maestro delight` injects micro-motion accents (orbital radar rings or breathing pulses)
- [ ] `/svg-maestro animate` transforms a static SVG into a motion asset using the Wrapper Pattern
- [ ] `/svg-maestro critique` emits a structured two-axis review scoring Technical Standards and Aesthetic Craft
- [ ] Refined SVGs pass linter validation with zero errors
